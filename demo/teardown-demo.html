Teardown demo

This page never writes the teardown key itself. The flow's steps phase plants a value in localStorage (qaloop_teardown) with a page-JS seed, and the teardown phase clears it again with the SPEC example form (seed js localStorage.clear()). The button below reads the stored value back out of the live page and renders it, so both the steps phase and the final teardown step can observe the exact planted state - or its absence after the clear.
