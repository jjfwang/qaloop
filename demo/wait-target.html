Wait: target demo

Every element on this page transitions state on a fixed timer from page load, driven only by the page script below. The flow's target-ful waits gate on exactly those transitions: the spinner starts visible and hides, the doomed element starts attached and detaches, the late element attaches only after a delay, and the status element's text changes last. If a transition does not happen, the matching wait times out and the step fails - the waits cannot pass vacuously.
